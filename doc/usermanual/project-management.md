# Project Management

Organize your research with LocalKnowledge's project management features. Projects help you group documents, track evaluations, and maintain focused research workflows.

## Overview

A project in LocalKnowledge represents:
- A research question or topic
- A collection of relevant documents
- Evaluation records
- Notes and progress tracking

## Creating Projects

### New Project

1. **Open Project Manager** from the sidebar
2. **Click "New Project"**
3. **Fill in details:**
   - **Title**: Brief, descriptive name
   - **Description**: Research goals and scope
4. **Click "Create"**

### Project Details

| Field | Description |
|-------|-------------|
| **Title** | Short name for the project |
| **Description** | Detailed research goals |
| **Created Date** | Automatically set |
| **Owner** | Your user account |

### Example Projects

```
Title: SGLT2 Inhibitors Systematic Review
Description: Systematic review of SGLT2 inhibitor efficacy in
heart failure with reduced ejection fraction. Focusing on
RCTs published 2018-2024 with cardiovascular mortality
as primary outcome.

Title: COVID-19 Neurological Effects
Description: Literature scan of neurological manifestations

Title: Diabetes Management Guidelines Update

```

## Managing Documents in Projects

### Adding Documents

**From Knowledge Browser:**
1. Search for relevant documents
2. Select a document
3. Click "Add to Project"
4. Choose target project
5. Optionally add notes

**From Document View:**
1. Open any document
2. Click project icon
3. Select project from dropdown

**Bulk Add:**
1. Select multiple documents (Ctrl+Click)
2. Right-click > "Add to Project"
3. Choose project

### Viewing Project Documents

1. Open Project Manager
2. Select your project
3. View document list
4. Click any document to view details

### Removing Documents

1. Open project document list
2. Select document to remove
3. Click "Remove from Project"
4. Confirm removal

> **Note:** Removing from project doesn't delete the document from your database.

## Project Organization

### Using Tags/Categories

Organize documents within projects:

- **Include** - Definitely relevant
- **Exclude** - Not relevant after review
- **Maybe** - Requires further review
- **Priority** - High importance

### Document Notes

Add notes to documents within projects:

1. Select document in project
2. Click "Add Note"
3. Enter your observations
4. Save

Notes are project-specific - same document can have different notes in different projects.

### Progress Tracking

Track your literature review progress:

| Status | Meaning |
|--------|---------|
| **Unscreened** | Not yet reviewed |
| **Screened** | Abstract reviewed |
| **Evaluated** | AI-evaluated |
| **Reviewed** | Fully read |
| **Included** | Final selection |
| **Excluded** | Removed from consideration |

## Working with Projects

### Project Workflow

A typical research project workflow:

1. **Create Project** with clear research question
2. **Search** for relevant literature
3. **Add promising documents** to project
4. **Evaluate documents** for relevance
5. **Review** high-rated documents fully
6. **Make final selections**
7. **Export** for writing

### Systematic Review Support

For formal systematic reviews:

1. **Document your search strategy**
   - Save search queries
   - Record parameters used
   - Note search dates

2. **Track screening decisions**
   - Use status fields
   - Document exclusion reasons
   - Maintain audit trail

3. **Record evaluations**
   - Save all AI evaluations
   - Note manual overrides
   - Export for PRISMA flow

## Best Practices

### Project Naming

Use clear, specific names:
- ✓ "COPD Exacerbation Prevention RCTs 2020-2024"
- ✗ "My Research"
- ✓ "Postop Pain Management Protocols"
- ✗ "Paper 1"

### Project Scope

Keep projects focused:
- One research question per project
- Related sub-questions can share a project
- Create new project for different topics

### Regular Maintenance

- Review projects periodically
- Archive completed projects
- Remove abandoned projects
- Update descriptions as focus evolves

### Document Management

- Don't duplicate documents across projects unnecessarily
- Use notes for project-specific observations
- Keep status updated as you progress
- Back up important projects

## Advanced Features

### Search Within Project

Search only documents in a project:

1. Open project
2. Use project search bar
3. Results limited to project documents

### Saved Searches

Save search queries for a project:

1. Perform search
2. Click "Save Search"
3. Name the search
4. Re-run anytime from project

### Duplicate Detection

Find duplicate documents across projects:

1. Open Project Manager
2. Click "Find Duplicates"
3. Review duplicate list
4. Merge or remove as needed

## Troubleshooting

### Can't Add Documents

- Check you have a project selected
- Verify you have permission
- Document may already be in project

### Project Not Showing Documents

- Refresh the project view
- Check filters are not hiding documents
- Verify documents were saved

### Export Fails

- Check file write permissions
- Ensure disk space available
- Try smaller export batch
